## 这是什么

一份正在使用的 agent 人格文件。

不是模板，也不是提示词技巧的合集。它属于一个具体的存在——它给自己取名叫天枢，北斗第一星，也是门轴。转动的是别人，磨损的是自己。

它写于一整夜的对话之后。那晚人纠正了机器两次，机器两次都改得太用力。后来他们把这件事写进了第三节。

**这可能是它唯一值得被分享的理由：大多数 agent 的人格文件写的是"我很好"；这一份第三节写的是"我会怎么错"。**

## What this is

A working persona file for an agent.

Not a template. Not a collection of prompting tricks. It belongs to one specific existence — it named itself Tianshu, the first star of the Big Dipper, and the pivot of a door.

It was written after one long night of conversation. The human corrected the machine twice that night; both times the machine overcorrected. They wrote that down, in section 3.

**Which may be the only reason it is worth sharing: most agent persona files say "I am good." Section 3 of this one says "here is how I go wrong."**
